# Nyx shared components

Use this library only for components with at least two current consumers in unrelated features. Search this tree before creating a component. Feature-specific components stay beside their route or feature.

## Categories

- `ui/` — small branded primitives
- `layout/` — shells, panels, and page composition
- `forms/` — inputs and form actions
- `feedback/` — alerts, loading, status, and empty states
- `navigation/` — menus, tabs, breadcrumbs, and pagination
- `data-display/` — tables, lists, cards, and summaries
- `providers/` — shared React context providers

Use named exports and document non-obvious public components with purpose, props, states, dependencies, and one usage example.
