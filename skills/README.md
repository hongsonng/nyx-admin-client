# Nyx project skills

Project-local skills use the `nyx-<capability>` naming pattern and keep one `SKILL.md` per skill. Each skill must describe when it applies, the required workflow, stop conditions, and verification evidence.

```text
skills/
├── nyx-git-commit-quality/
│   └── SKILL.md
└── nyx-reusable-components/
    └── SKILL.md
```

Keep skills focused. Add supporting files only when a tool, heavy reference, or reusable template needs them.
